# mongolia-mcp

An [MCP](https://modelcontextprotocol.io) server with small, correct utilities for Mongolian developers. Plug it into Claude (or any MCP client) and stop pasting Mongolian reference data into prompts.

## Tools

| Tool | What it does |
| --- | --- |
| `romanize_mongolian` | Cyrillic to Latin using the national standard **MNS 5217:2012** (`Хөвсгөл` -> `Khövsgöl`, `Цэцэрлэг` -> `Tsetserleg`). Optional `ascii` flag drops the umlauts. |
| `lookup_mongolian_place` | Find an aimag, aimag capital, soum, or Ulaanbaatar district by name. Accepts Cyrillic and the spellings people actually type (`Khuvsgul`, `Hovsgol`, `Uvurkhangai`, `Bayan-Ulgii`). |
| `list_mongolian_aimags` | All 21 aimags plus Ulaanbaatar, with codes, Cyrillic and English names and capitals. |
| `list_mongolian_soums` | The 330 soums with their codes, optionally filtered by aimag (`aimag: "Khuvsgul"`). |
| `list_ulaanbaatar_districts` | The 9 districts of Ulaanbaatar. |

Example:

> **You:** Give me a Prisma enum for Mongolian aimags using romanized names.
> **Claude:** *(calls `list_mongolian_aimags`, then `romanize_mongolian`)*

## Install

**Claude Code**

```bash
claude mcp add mongolia -- npx -y mongolia-mcp
```

**Claude Desktop** (`claude_desktop_config.json`)

```json
{
  "mcpServers": {
    "mongolia": {
      "command": "npx",
      "args": ["-y", "mongolia-mcp"]
    }
  }
}
```

## Data sources

Place data links to where it came from. The romanization table follows MNS 5217:2012, which has no free official copy online to link; a link to one is a welcome contribution.

| Data | Source | Notes |
| --- | --- | --- |
| Aimag, district and soum codes; soum names | [OCHA COD-AB Mongolia v01](https://data.humdata.org/dataset/cod-ab-mng) (sheets `mng_admin1`, `mng_admin2`) | Original source: National Statistical Office of Mongolia. Licence: [CC BY-IGO](https://docs.humdata.org/about/data-licenses). Reviewed by OCHA on 30 October 2025. Regenerate with `scripts/build-soums.mjs`. |

Codes are the National Statistical Office administrative unit codes (`67` Khövsgöl, `6728` Renchinlkhümbe). Prefix `MN` to get the OCHA P-code (`MN6728`).

## Limitations (read these)

- **Romanization is one-way and lossy.** MNS 5217:2012 maps `й`, `ь` and `ъ` all to `i`, so you cannot reliably go back to Cyrillic. Real-world usage also doesn't follow the standard consistently, so don't expect it to match every passport or street sign.
- **Place data stops at the second level.** 21 aimags, their capitals, 330 soums, Ulaanbaatar, and its 9 districts. **Bags and khoroos are not included**: OCHA publishes boundaries down to soum level only, and no complete, current list from the National Statistical Office could be verified.
- **Soum names are copied verbatim from the source**, including a few spellings that differ from common usage: `Шарын гол` (usually Шарынгол), `Есөн зүйл` (Есөнзүйл), `Гурван булаг` in Bulgan (Гурванбулаг), `Их тамир` (Ихтамир), `Хишиг-өндөр` (Хишиг-Өндөр) and `Өмнөгөвь` in Uvs (Өмнөговь). Lookup matches both forms.
- **Soum Latin names are MNS 5217:2012 romanizations** of the Cyrillic name, not official English names.
- **Name matching is fuzzy on purpose.** Names collide (Sükhbaatar is an aimag, a city, two soums and a UB district), so lookups return every match instead of guessing.
- Khentii's capital is listed as **Chinggis** (renamed from Öndörkhaan in 2013). The old name still matches.

## Roadmap

Good first contributions, roughly in order of usefulness:

- [x] Soums (OCHA COD-AB)
- [ ] Bags and khoroos, once a complete and current official list can be linked
- [ ] Public holidays and the lunar calendar (Tsagaan Sar), only with a verified algorithm or a verified table
- [ ] Traditional Mongolian script support
- [ ] ISO 3166-2:MN codes for first-level divisions, checked against the [ISO Online Browsing Platform](https://www.iso.org/obp/ui/#iso:code:3166:MN)

If you add data, please link the source in the PR. Wrong data is worse than missing data.

## Development

```bash
npm install
npm test        # vitest
npm run build   # tsc -> dist/
```

Logic lives in `src/romanize.ts` and `src/divisions.ts` as plain functions. `src/soums.data.ts` is generated by `scripts/build-soums.mjs`; don't edit it by hand. `src/server.ts` only wires them to MCP tools.
